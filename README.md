# Spambots and Fake Followers Detection

## Description
This project is developed to identify spambots and fake followers on social media platforms using Machine Learning techniques. The system analyzes user profile and behavioral features to classify accounts as genuine or fake.

## Features
- Spambot Detection
- Fake Follower Identification
- Machine Learning Prediction
- User-Friendly Web Interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Scikit-learn
- Pandas
- NumPy

## Models Used
- Logistic Regression
- Support Vector Machine (SVM)

 ## How to Run
pip install -r requirements.txt
python app.py
Open: http://127.0.0.1:5000
